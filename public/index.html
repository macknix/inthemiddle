  • Once two or more people have pins, hit Find the middle — everyone sees the same results. Tap a numbered pin for each person's route and times.
  • The tabs at the top: the people icon is this shared room; the pin icon is manual mode — type 2–5 addresses yourself, no sharing involved.
  • Options changes the max travel time and departure time.
